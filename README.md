# 🏎️💥 CYBER NITRO: Combat Racing Arena
### Built for the Handshake AI Skills Studio × OpenAI Multiplayer Game Challenge

![Cyber Nitro Cover](cover.jpg)

**CYBER NITRO** is an adrenaline-fueled, action-packed multiplayer game combining **high-speed racing, drifting physics, and vehicular combat shooting** all in one!

---

## ⚡ Game Features & Mechanics

- **🏎️ High-Speed Combat Racing:** 3-Lap death race around an asphalt cyber arena with checkpoint gating, boost pads, and obstacle collisions.
- **🔫 Real-time Vehicular Shooting:**
  - **Plasma Gatling Guns:** Rapid-fire energy projectiles with lead-aim physics.
  - **Homing Rockets & Lasers:** Heavy damage pick-ups scattered across the track.
  - **Proximity Landmines:** Drop deadly traps behind you for tailgating opponents!
- **⚡ Nitro Boost & Handbrake Drifting:** Burn nitro fuel to hit hyper-velocity and drift around tight hairpins.
- **📱 Cross-Device Real-Time Multiplayer:**
  - Host a match on PC/TV screen.
  - Friends scan the dynamic **QR code** on their smartphones to join the grid instantly.
  - Full mobile on-screen touch controls (Steering buttons, Drive/Reverse, Nitro pedal, Fire button) + Desktop keyboard support (`WASD` / Arrows + `SPACE` to shoot + `SHIFT` for Nitro).
- **🤖 Smart AI Combat Bots:** Click `+ Add AI Combat Racer` to populate the grid with aggressive pathfinding bots that steer, drift, and shoot at nearby targets.
- **🔊 Procedural Web Audio Engine:** Dynamic engine hums, weapon blasters, explosion booms, and countdown beeps generated in real time without external audio files.

## 🕹️ Controls

| Action | Desktop Controls | Mobile Touch Controls |
| :--- | :--- | :--- |
| **Accelerate / Reverse** | `W` / `S` or `▲` / `▼` | `▲ DRIVE` / `▼ REV` |
| **Steer Left / Right** | `A` / `D` or `◀` / `▶` | `◀` / `▶` Buttons |
| **Fire Weapons** | `SPACEBAR` | `🔥 FIRE` Button |
| **Nitro Turbo Boost** | `LEFT SHIFT` | `⚡ NITRO` Button |
| **Handbrake Drift** | `E` or `C` | `💨 DRIFT` Button |
